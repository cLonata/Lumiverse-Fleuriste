ATELIER CHAT COMMANDS v1 — leave this help entry disabled.
Commands are plain chat messages, not custom-registered slash commands. Use !atelier followed by a verb and task text. !nemo is accepted as a compatibility alias for the same verbs while using Atelier; it does not enable Nemo Engine features.
look / inspect / describe: static visual description from the current knowledge; no fictional time, action, discovery or resource progression.
recap: summarize established events. explain: answer using known facts and label uncertainty. options: outline possibilities without executing them. ask: separate meta question.
note: attach one-time guidance to the next ordinary story reply without pausing that story reply. clear-notes: clear pending notes.
set: explicit Runtime update (Manual/Auto only). setup: initialize Runtime without advancing fiction; if configuration already exists, report it rather than overwrite. show/status: read-only settings. checkpoint: write a complete saved Runtime snapshot when Manual/Auto allows a change. help: list usage.
A task-only command holds the current fictional instant for that response. No scene time, narrator cutaway, NPC action, resources, or counters progress. The next ordinary RP reply resumes from the same instant, no resume command required. An OOC direction alone is not a task; it guides the story unless it explicitly requests a separate answer or a persistent Runtime edit. Quotes or code fences are not executable commands.
When Runtime is disabled, look, inspect, recap, ask and notes still work, but set/setup/checkpoint cannot change saved preferences.

Success Dice Hidden/Visible are mutually exclusive Prompt Manager toggles, not !atelier set fields. Both off disables Success Dice. Commands look/inspect/recap/options/status/setup do not roll or advance the fictional moment. Status may report which dice mode is active, but must not reveal unspent dice or private results from Hidden mode.
